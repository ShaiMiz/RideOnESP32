# Bill of materials

The project has one BOM: [kicad/BOM.md](kicad/BOM.md) (and [BOM.csv](kicad/BOM.csv) for a spreadsheet). It lists every part of the car, every tool and material, and the spares on hand, with status (owned, ordered, to buy, TBD, stock), manufacturer and part number, order line and cost.

This file held the first parts list, from the gear photos of 17 Oct 2026. Everything in it is now in the BOM above.
