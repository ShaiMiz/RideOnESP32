                                                                                                                                                                                                                                                                                                                                                                                                                                                            ## 1. Introduction

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 1.1 Project Overview

                                                                                                                                                                                                                                                                                                                                                                                                                                                            This manual covers the ESP32-based replacement control system for the Power Wheels Can-Am Maverick X3 ride-on vehicle. The original control board has been replaced with a modern, feature-rich system offering:

                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Dual Control Modes:** Manual (pedal/shifter) and Remote (radio control)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Advanced Motor Control:** Independent 4-wheel drive with BTS7960 H-bridge drivers
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Safety Features:** Voltage monitoring, overcurrent protection, thermal management
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Radio Control:** ExpressLRS 2.4GHz long-range system
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Real-time Telemetry:** Battery, current, and motor monitoring

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 1.2 Key Features

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **4x Independent Motor Control** - Each wheel controlled separately  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **24V High-Power System** - 4x 200W motors (800W total)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Dual Control Modes** - Switch between manual and radio control  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Multi-speed Operation** - Reverse, Low, and Fast modes  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Advanced Safety Systems** - Multiple protection mechanisms  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Real-time Monitoring** - Battery voltage, current, temperature  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Radio Failsafe** - Automatic shutdown if signal lost  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ **Expandable** - I/O expander and display support  

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 1.3 Who This Manual Is For

                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Primary Users:** Parents/guardians assembling and maintaining the vehicle
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Secondary Users:** Advanced hobbyists and makers

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ## 3. Hardware Specifications

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 3.1 Main Components

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### ESP32-WROOM-32U Microcontroller
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Processor:** Dual-core Xtensa LX6 @ 240MHz
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **RAM:** 520KB SRAM
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Flash:** 4MB
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **GPIO:** 34 pins (26 usable in this project)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **ADC:** 12-bit, 18 channels (using ADC1 only)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **PWM:** 16 channels (using 8 for motors)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Communication:** UART, I2C, SPI
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Power:** 3.3V @ 200mA typical

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### BTS7960 Motor Drivers (4 units)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Main Chip:** Infineon BTS7960 H-Bridge
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Continuous Current:** 43A per driver
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Peak Current:** 100A per driver (short duration)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Operating Voltage:** 6V-27V (motor power)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Logic Voltage:** 3.3V-5V compatible
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **PWM Frequency:** Up to 25kHz (configured at 1kHz)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Protection:** Thermal shutdown, overcurrent, short circuit
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Current Sensing:** R_IS and L_IS outputs (1mV/A typical)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Control:** Dual PWM (RPWM forward, LPWM reverse)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Motors (4 units)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Type:** Brushed DC motors
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Voltage:** 24V nominal
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Power:** 200W each (800W total)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Speed:** 22,000 RPM no-load
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Current:** 8-10A typical per motor under load
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Peak Current:** 15-20A per motor (startup/stall)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Power Supply Components

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Batteries:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Configuration: Dual 12V in series OR single 24V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Type: Lead-acid or LiPo (6S)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Capacity: Recommended 7Ah minimum
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Voltage Range: 19V (cutoff) to 27V (full charge)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **XH-M609 Battery Protection:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low voltage disconnect: ~20V (adjustable)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Over-voltage disconnect: ~29V (adjustable)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Current capacity: 30A continuous

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **30A Circuit Breaker:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Manual reset type
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Mounting location: Easily accessible
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Purpose: Emergency disconnect and overcurrent protection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **LM2596 Buck Converters (2 units):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Input: 4.5V-40V (powered from 24V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Output #1: 3.3V @ 3A (for ESP32 and logic)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Output #2: 12V @ 2A (for accessories)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Efficiency: ~92%
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Protection: Thermal shutdown, current limiting

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Radio Control System

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Jumper AION-RX-MINI Receiver:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Protocol: ExpressLRS (CRSF)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Frequency: 2.4GHz
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Channels: 16
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Range: Up to 5km
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Voltage: 3.5V-6V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Current: 60mA @ 5V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Output: Serial CRSF @ 420000 baud
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Latency: <10ms typical

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Transmitter:** Jumper T-Lite V2 (not included)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - ExpressLRS 2.4GHz compatible
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Multi-protocol support
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Telemetry capable

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 3.2 Optional Components

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ## 5. Safety Systems

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 5.1 Hardware Protection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 1. Battery Protection (XH-M609)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Prevents battery over-discharge and over-voltage  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Trigger Conditions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low voltage: <20V (adjustable)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - High voltage: >29V (adjustable)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Disconnects battery output
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Recovery:** Manual reset or automatic when voltage returns to safe range

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 2. Circuit Breaker (30A)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Overcurrent and emergency disconnect  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Trigger Condition:** Current draw exceeds 30A  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Opens circuit (manual reset required)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Location:** Main battery positive line, easily accessible

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 3. BTS7960 Thermal Protection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Prevents driver overheating  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Trigger Condition:** Internal chip temperature >150°C  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Automatic shutdown of affected driver  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Recovery:** Automatic when cooled below ~130°C

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 4. BTS7960 Current Limiting
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Prevents overcurrent damage  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Specification:** 43A continuous, 100A peak  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Built-in current limiting and thermal foldback

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 5.2 Software Protection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 1. Low Voltage Cutoff
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Threshold:** 19.0V (configurable in code)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Warning:** 21.0V  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Disables all motors, logs warning  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Display:** "SAFETY: Low battery voltage - Motors disabled!"

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 2. Overcurrent Protection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Limit:** 40.0A total (configurable)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Warning:** 35.0A  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Emergency stop, motors disabled  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Display:** "SAFETY: Overcurrent detected - Motors disabled!"

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 3. Thermal Monitoring
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Trigger:** Over-temperature fault pin (active LOW)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Recovery Time:** 30 seconds forced cooldown  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Emergency stop, motors disabled  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Display:** "!!! OVER-TEMPERATURE FAULT DETECTED !!!"

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 4. Radio Failsafe (Remote Mode Only)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Timeout:** 1000ms (1 second) no valid signal  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Detection:** CRSF channel values out of range (900-2100)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Action:** Immediate emergency stop  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Display:** "SAFETY: Radio signal lost - Motors disabled!"  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Recovery:** Automatic when signal restored

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### 5. Motor Ramping
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Prevents sudden torque changes (gear damage prevention)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Ramp Rate:** 10 PWM units per 20ms (0-100% in ~510ms)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Application:** All speed changes (acceleration and deceleration)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 5.3 Safety System Priority

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Highest Priority → Lowest Priority:**

                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. **Hardware Protection** (Circuit breaker, XH-M609) - Cannot be overridden
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. **Thermal Shutdown** (BTS7960 chip-level) - Automatic hardware protection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. **Software Emergency Stop** (Overcurrent, over-temperature) - Immediate
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. **Radio Failsafe** (Remote mode only) - 1-second timeout
                                                                                                                                                                                                                                                                                                                                                                                                                                                            5. **Low Voltage Warning** (Pre-cutoff alert) - Graceful shutdown warning
                                                                                                                                                                                                                                                                                                                                                                                                                                                            6. **Motor Ramping** (Mechanical protection) - Always active

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Star Ground Configuration:**

                                                                                                                                                                                                                                                                                                                                                                                                                                                                        [Common GND Point]
                                                                                                                                                                                                                                                                                                                                                                                                                                                                        (large terminal block)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                │
                                                                                                                                                                                                                                                                                                                                                                                                                                                                    ┌─────────────┼─────────────┬──────────────┐
                                                                                                                                                                                                                                                                                                                                                                                                                                                                    │             │             │              │
                                                                                                                                                                                                                                                                                                                                                                                                                                                                    ↓             ↓             ↓              ↓
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ESP32 GND    BTS7960 GND    LM2596 GND    ELRS GND
                                                                                                                                                                                                                                                                                                                                                                                                                                                                            (all 4)         (both)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```

Operation Guide

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.1 Pre-Operation Checklist

                                                                                                                                                                                                                                                                                                                                                                                                                                                            Before each use:

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Check battery voltage (>21V for safe operation)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Inspect all wiring for damage or loose connections  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Verify motors spin freely (no mechanical binding)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Test circuit breaker (accessible and functional)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Check tire pressure and condition  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Verify weight capacity not exceeded  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Ensure operating area is safe (flat, clear of obstacles)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Bind ELRS receiver to transmitter (if not already bound)  

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.2 Startup Procedure

                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. **Power On Sequence:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Close circuit breaker (if open)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Wait for ESP32 to boot (~2 seconds)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Listen for initialization sounds (optional buzzer)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check Serial Monitor output (if connected)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. **Verify Initialization:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - ELRS receiver LED should be solid (bound) or flashing (searching)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - OLED display (if installed) shows startup screen
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - No error beeps or warnings

                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. **Radio Check (Remote Mode):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Turn on transmitter
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Wait for receiver to connect (solid LED)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Move sticks - verify response (check telemetry or display)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Test failsafe: turn off transmitter → vehicle should stop

                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. **Manual Mode Check:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Set mode switch to Manual
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Press pedal slightly → no movement (should be in PARK)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Move shifter to DRIVE → verify direction indicator
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Press pedal → slow movement
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Move shifter to REVERSE → verify direction change

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.3 Control Modes

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Manual Mode (Pedal & Shifter Control)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Shifter Positions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **PARK:** Both switches open → No motor movement (safe state)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **DRIVE:** D switch closed → Forward direction enabled
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **REVERSE:** R switch closed → Reverse direction enabled

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Pedal Operation:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - No press: 0% speed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Light press: ~30% speed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Medium press: ~60% speed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Full press: 100% speed

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Lights:** Always ON in manual mode

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Speed Limiting:** None (full power available in manual mode)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Remote Mode (Radio Control)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Required Setup:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Transmitter: Jumper T-Lite V2 or compatible ELRS radio
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Receiver: Must be bound and connected (solid LED)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Mode switch: Set to REMOTE

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Channel Mapping:**

                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Channel | Control | Function | Values |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            |---------|---------|----------|--------|
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **0** | Throttle | Left stick vertical | 1000 (idle) → 2000 (full) |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **1** | Steering | Right stick horizontal | 1000 (left) → 2000 (right) |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **2** | Horn | Button/switch | >1500 = active |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **3** | Mode Switch | 2-position | <1500 Manual, >1500 Remote |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **5** | Lights | 2-position | <1500 Off, >1500 On |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | **6** | Speed Mode | 3-position | <1300 Rev, 1300-1700 Low, >1700 Fast |

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Speed Modes:**

                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. **REVERSE (<1300):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Motors run in reverse
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Full power available
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use caution - same power as forward

                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. **FORWARD LOW (1300-1700):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Forward direction
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Speed limited to 50% maximum
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Best for beginners or tight spaces
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Safer for younger children

                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. **FORWARD FAST (>1700):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Forward direction
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Full power available
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Maximum speed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - For experienced drivers only

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Failsafe Behavior:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Radio signal lost for >1 second
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - All motors immediately stop
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Vehicle enters safe state
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Warning logged (if display installed)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Automatic recovery when signal restored

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.4 Speed Control

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Acceleration:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Gradual ramping prevents gear damage
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - 0 → 100% in ~510ms
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Adjust RAMP_STEP in code for faster/slower response

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Deceleration:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Same ramping applies when reducing speed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Emergency stop bypasses ramping (instant)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Braking:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Release throttle/pedal → gradual deceleration
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Motors electrically brake (not coast)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.5 Emergency Procedures

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Emergency Stop Methods:

                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. **Circuit Breaker:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Location: Front of vehicle (accessible)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Action: Flip breaker switch to OFF
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Result: Immediate power disconnect
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use for: Electrical emergency, runaway vehicle

                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. **Release Controls:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Manual: Release pedal
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Remote: Release throttle stick to center
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Result: Gradual deceleration (~500ms)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use for: Normal stops, controlled slowdown

                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. **Mode Switch:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Switch to Manual mode and shifter to PARK
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Result: Immediate motor disable
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use for: Quick stop when in remote mode

                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. **Turn Off Transmitter (Remote Mode):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Turn off transmitter
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Result: Failsafe triggers, motors stop within 1 second
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use for: Testing failsafe, emergency in remote mode

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Common Issues During Operation:

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Vehicle stops suddenly:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check battery voltage (may be <19V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check for over-temperature (let cool 30 seconds)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check radio signal (if in remote mode)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check serial monitor for error messages

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Vehicle sluggish:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low battery voltage (recharge)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Motors overheating (let cool down)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Mechanical binding (check wheels/gears)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check motor current (may be overloaded)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Erratic behavior:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Radio interference (move away from WiFi routers)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Loose wiring (inspect connections)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low transmitter battery (replace)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check serial monitor for diagnostic info

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 9.6 Shutdown Procedure

                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. **Stop Vehicle:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Bring to complete stop (release throttle/pedal)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Shifter to PARK (manual mode)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Turn off transmitter (remote mode)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. **Power Off:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Open circuit breaker
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Wait 5 seconds for capacitors to discharge

                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. **Post-Operation Checks:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Feel BTS7960 heatsinks (should not be too hot to touch)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check battery voltage (note for next charge cycle)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Inspect wiring for any damage or looseness
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check tires and mechanical components

Control Modes

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 10.1 Manual Mode Details

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Traditional Power Wheels operation using physical controls

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Best For:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Younger children (3-6 years)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Learning to drive
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Close supervision
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Predictable operation

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Characteristics:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Physical pedal provides tactile feedback
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Shifter gives clear indication of direction
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Lights always on (visibility)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - No radio dependence
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Simple operation

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Limitations:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - No speed limiting (full power in both directions)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - No failsafe (relies on physical controls only)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Current sensing limited (pedal uses ADC pin)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 10.2 Remote Mode Details

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Purpose:** Adult-controlled operation via radio transmitter

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Best For:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Very young children (2-4 years)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Teaching steering skills
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Crowded areas (precise control)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Demo/show operation
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Safety-critical situations

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Characteristics:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Complete control from transmitter
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Adjustable speed modes (Low/Fast)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Radio failsafe protection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Can override child's actions
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Lights controllable

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Advanced Features:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Speed mode selection (3 positions)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Steering trim adjustment (transmitter-side)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Telemetry feedback (optional)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Multiple child profiles (transmitter presets)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 10.3 Mode Switching

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **How to Switch:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Manual → Remote: Move mode switch on transmitter to Remote position
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Remote → Manual: Move mode switch to Manual position

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **When Mode Changes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Motors immediately respond to new control source
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Shifter state read (manual mode)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Speed mode applied (remote mode)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Lights behavior changes

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Safety During Switching:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Current motor speed is maintained momentarily
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Ramping still applies (no sudden changes)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - If controls conflict, system chooses safe default (slower speed)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ## 11. Troubleshooting

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 11.1 Power Issues

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: ESP32 won't power on

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** No LED, no serial output, no activity

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. No 3.3V from LM2596 #1
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Loose/broken USB cable (if powering via USB)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Damaged ESP32

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Measure voltage at LM2596 #1 output (should be 3.3V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Adjust LM2596 potentiometer if needed
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Try different USB cable
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check for shorts between 3.3V and GND
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify ESP32 VIN pin connection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: BTS7960 drivers not working

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Motors don't run, no PWM output

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. No 24V at B+ terminal
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. R_EN/L_EN not enabled
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. BTS7960 in thermal shutdown
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Damaged driver

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Measure voltage at B+ (should be 24V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check GPIO 21 is HIGH (motor enable)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Feel heatsink (if very hot, wait for cooldown)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Test with different motor
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Swap BTS7960 with known working unit

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: System reboots randomly

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** ESP32 resets during operation

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Brownout (voltage dip below 2.8V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Overcurrent on 3.3V rail
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. EMI from motors
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Loose power connection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Add bulk capacitor (1000µF) on 3.3V rail
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check all 3.3V connections are tight
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Route signal wires away from motor wires
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Add ferrite beads on motor power lines
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify LM2596 output voltage stable under load

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 11.2 Motor Issues

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Motors don't spin

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** No movement when controls applied

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Safety system active (check serial monitor)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Motors not connected
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. BTS7960 not enabled
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Mechanical binding

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check serial monitor for error messages:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low voltage? → Charge battery
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Overcurrent? → Check for short circuit
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Over-temp? → Wait 30 seconds for cooldown
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify motor connections (M+ and M-)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check GPIO 21 (motor enable) is HIGH
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Manually spin wheels (should turn freely)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Test motors with bench power supply

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Motors spin wrong direction

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Forward command causes reverse (or vice versa)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Swap M+ and M- wires on that motor
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. OR change pin assignments in code:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```cpp
                                                                                                                                                                                                                                                                                                                                                                                                                                                            // Swap RPWM and LPWM pin numbers for that motor
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: One motor weaker than others

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Vehicle pulls to one side, uneven current draw

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Damaged motor
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Mechanical binding on that wheel
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Loose motor connection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Weak BTS7960 driver

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check motor current (serial telemetry)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Swap motors to isolate problem
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Inspect gearbox for damage
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify all motor connections tight
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Test with different BTS7960 driver

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Motors stutter or jerk

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Unsmooth operation, pulsing

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Low battery voltage
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Loose connections
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. PWM frequency too low
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. EMI interference

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Charge battery (check voltage >21V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Tighten all power connections
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Increase PWM frequency in code (try 5kHz):
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```cpp
                                                                                                                                                                                                                                                                                                                                                                                                                                                            const int PWM_FREQ = 5000;
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Add capacitors (0.1µF) across motor terminals

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 11.3 Radio Issues

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: ELRS receiver won't bind

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** LED flashing rapidly, no connection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Put transmitter in bind mode first
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Power on receiver (should flash green)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Wait 20 seconds for WiFi update mode
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Access receiver via WiFi (http://10.0.0.1)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            5. Manually bind via web interface
                                                                                                                                                                                                                                                                                                                                                                                                                                                            6. Verify correct ELRS firmware version (2.4 GHz)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Frequent failsafes

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Vehicle stops randomly, signal lost messages

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Low transmitter battery
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Antenna damaged or poorly positioned
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. EMI from motors
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. Out of range

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Replace transmitter batteries
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Reposition receiver antenna (vertical, clear view)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Move receiver away from BTS7960 drivers
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Reduce distance to vehicle
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check transmitter output power setting

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: High latency

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Delayed response to stick inputs

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. ELRS mode set to long-range (slower update rate)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Radio interference

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Change ELRS mode to faster rate (e.g., 250Hz)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Move away from WiFi routers
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check for other 2.4GHz devices

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 11.4 Sensor Issues

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Battery voltage reading incorrect

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Voltage much higher/lower than actual battery voltage

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Wrong voltage divider ratio in code
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Resistor values incorrect
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Loose connection

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Measure actual battery voltage with multimeter
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Measure voltage at GPIO 35 (should be battery / 9.333)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify resistor values (100kΩ and 12kΩ)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Adjust VOLTAGE_DIVIDER_RATIO in code if needed:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```cpp
                                                                                                                                                                                                                                                                                                                                                                                                                                                            // Measured values:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            // Battery = 24.0V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            // GPIO 35 = 2.5V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            // Ratio = 24.0 / 2.5 = 9.6
                                                                                                                                                                                                                                                                                                                                                                                                                                                            const float VOLTAGE_DIVIDER_RATIO = 9.6;
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Current reading always zero

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Motor current shows 0.0A even when motors running

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. R_IS/L_IS pins not connected
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Wrong sensitivity value
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Reading in manual mode (GPIO conflict)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify R_IS/L_IS wiring to ESP32 ADC pins
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check current sense only works in REMOTE mode
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Try different sensitivity value:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```cpp
                                                                                                                                                                                                                                                                                                                                                                                                                                                            const float BTS7960_CURRENT_SENSITIVITY = 0.0005; // Try 0.5mV/A
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Measure voltage at R_IS pin with multimeter (should be >0V when motor running)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Thermal fault triggering incorrectly

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Symptoms:** Over-temp warning when drivers are cool

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Possible Causes:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            1. Diode orientation wrong
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Pull-up resistor missing
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3. Loose connection
                                                                                                                                                                                                                                                                                                                                                                                                                                                            4. GPIO 19 floating

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check diode orientation (cathode toward GPIO 19)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Verify 10kΩ pull-up resistor from GPIO 19 to 3.3V
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Test: disconnect fault pins, check if problem persists
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Short GPIO 19 to GND → should trigger fault (if not, wiring issue)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 11.5 Software Issues

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **For ledcAttach() error:** Use ESP32 board package v3.x or later
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Arduino IDE: Update via Boards Manager
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - PlatformIO: Check `platformio.ini` platform version
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **For library errors:** Install missing libraries (see Section 8.3)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Check serial output** for specific error details

                                                                                                                                                                                                                                                                                                                                                                                                                                                            #### Problem: Firmware won't upload

                                                                                                                                                                                                                                                                                                                                                                                                                                                            - `A fatal error occurred`

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Solutions:**

Hold BOOT button on ESP32 while clicking upload
                                                                                                                                                                                                                                                                                                                                                                                                                                                            2. Try different USB cable
                                                                                                                                                                                                                                                                                                                                                                                                                                                            3.                                                                                                                                                                                                                                                                                                                                                                                                                                                             4. Install/update CH340 or CP2102 drivers
                                                                                                                                                                                                                                                                                                                                                                                                                                                            5. Reduce upload speed:

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Clean dust/debris from vehicle

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Full system inspection  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Test all safety systems:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Low voltage cutoff (discharge battery to 19V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Overcurrent protection (load test)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Thermal shutdown (heat driver with heat gun - carefully!)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Radio failsafe (turn off transmitter)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Clean battery terminals  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Check motor current balance (all 4 should be similar)  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Verify voltage divider accuracy  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Update firmware if new version available  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Backup configuration settings  

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 12.4 Seasonal (or every 50 hours of operation)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Deep clean all components  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Replace thermal paste on BTS7960 heatsinks  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Inspect motor brushes, replace if worn  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Check gearbox lubrication

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Re-apply heat shrink tubing if damaged  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            ✅ Check ESP32 for signs of overheating  

                                                                                                                                                                                                                                                                                                                                                                                                                                                            ### 12.5 Battery Maintenance

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Lead-Acid Batteries:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Charge after each use
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Don't store discharged (<50%)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Check water level monthly (if not sealed)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Replace every 1-2 years

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **LiPo Batteries (6S):**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Charge after each use (don't leave discharged)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Store at storage voltage (3.8V per cell = 22.8V)
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Balance charge every 10 cycles
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Inspect for puffing/damage before each use
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Replace immediately if damaged
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Never discharge below 18V (3.0V per cell)

                                                                                                                                                                                                                                                                                                                                                                                                                                                            **Charging Safety:**
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Use appropriate charger for battery type
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Charge in fireproof location
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Never leave charging unattended
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Disconnect if battery gets hot
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - Follow manufacturer's charging current limits

                                                                                                                                                                                                                                                                                                                                                                                                                                                            |---------|-----------------|
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | No power | Battery voltage, circuit breaker, LM2596 outputs |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Motors don't run | Serial monitor errors, GPIO 21 enable, BTS7960 connections |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Wrong direction | Swap M+ and M-, or swap RPWM/LPWM in code |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Random stops | Battery voltage, thermal, radio signal |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Radio won't bind | Transmitter in bind mode first, correct ELRS version |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Voltage wrong | Measure with multimeter, adjust divider ratio |
                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Current always 0A | Only works in REMOTE mode, check R_IS/L_IS wiring |
